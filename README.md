# Flutter Calculator

A calculator app built with Flutter, using the Provider package for state management.

- **Built:** May 2024
- **Stack:** Flutter / Dart, Provider, flutter_screen_scaler, auto_size_text

## Features
- Standard arithmetic operations (+, −, ×, ÷, %)
- Responsive UI that scales across screen sizes
- Clean separation of UI (`buttons.dart`, `home.dart`) and logic (`functions.dart`)

## Getting Started
This is a standard Flutter project.

```bash
flutter pub get
flutter run
```
